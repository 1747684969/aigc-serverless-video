# 实测数据与成本口径

> 所有数字均为**本项目在本机 + Modal 上的实际观测值**，非理论估算。
> 若你要在自己的环境复现，硬件与单价不同，结果会有差异。

## 1. 测试条件

| 项 | 值 |
|---|---|
| 分辨率 / 帧数 | 1344×768 / 124 帧（≈5s @24fps，官方 17k+5 帧网格） |
| 采样步数 | 8 步（Turbo LoRA）；对比组 20 步（标准） |
| 云端 GPU | A100-40GB |
| Modal 单价 | **约 $3.29 / 小时**（A100-40GB） |
| 模型总量 | 约 26GB（UNet int8 ~9GB + Qwen3VL-32B ~17GB + VAE/LoRA） |
| 本地设备 | RTX 3050 Laptop，**4GB 显存** |

## 2. 端到端耗时分解

| 阶段 | 冷启动（优化前 20 步） | 冷启动（优化后 8 步） | 热容器 |
|---|---|---|---|
| 容器 + ComfyUI 启动 | 0.5–1 min | 0.5–1 min | 0 |
| **从 Volume 加载 26GB 模型** | **3–6 min** | **3–6 min** | **0（已在显存）** |
| 采样 | 2–3 min | ~1 min | ~1 min |
| 解码 + 封装 | 0.5–1 min | 0.5–1 min | 0.5–1 min |
| **合计** | **6–11 min** | **5–8 min** | **1.5–2 min** |

## 3. 成本折算

按 $3.29/小时：

| 场景 | 折算成本 |
|---|---|
| 冷启动 + 20 步 | $0.33 – 0.60 |
| 冷启动 + 8 步 | $0.28 – 0.44 |
| **热容器 + 8 步** | **$0.08 – 0.11** |

**$30 预算能出多少片：**

- 全部冷启动：约 **70–100 片 / 月**
- 会话内连拍（热容器）：约 **270–370 片 / 月**

## 4. 关键结论（反直觉的部分）

1. **成本大头不是采样步数，而是每次冷启动读 26GB 模型的 3–6 分钟。**
   - 8 步 Turbo LoRA 只省 ~15–25%（省的是采样那 1–2 分钟）；
   - **热容器复用省 ~75%**（省掉整个模型加载过程）。

2. **所以最有效的优化是提高容器复用率，而不是一味压步数。**

3. **`scaledown_window` 要按使用习惯调：**
   - 习惯**连续出片** → 调大到 300–600s，收益最大；
   - 习惯**出一片就走** → 120s 窗口会多付约 $0.11 闲置费，反而应调小。

4. **一个容易忽略的事实**：完全没有输出的失败请求几乎不花钱（只烧十几秒容器时间）。
   所以"修好功能"和"省钱"是两件事——真正开始产生费用，是从功能可用那一刻起。

## 5. 其他成本项（量级很小）

| 项 | 成本 |
|---|---|
| Volume 存储（~26GB） | ≈ **$0.57 / 月**（$0.022/GB-month） |
| 镜像构建（每次约 50s，构建 worker） | 约 $0.14 / 次 |
| 视频封装（ffmpeg） | 可忽略 |

## 6. 未采用/被否决的优化

| 方案 | 否决原因 |
|---|---|
| `keep_warm=1` 常驻容器 | 一天约 **$79**，个人使用不划算 |
| 降分辨率 / 降时长 | 直接损质量 |
| `turbo_steps < 8` | 官方 LoRA 只训练到 8 步 |
| 换 nvfp4 量化 | 需 Blackwell（H100+），A100 不可用，反而更贵 |
| 模型打进镜像 | 镜像膨胀到 9GB+17GB，部署极慢 |
| L40S（48GB，$1.89/hr） | 理论可省约 43%，但 32B CLIP + UNet + 激活可能 OOM，需实测；未作为默认 |
| 云端 4x 放大 | 124 帧 4x 张量约 29GB，不可行 |
| 云端 2x 放大 | 可行，但增加 $0.03–0.08/片；改由本地后处理承担 |

## 7. 本地后处理实测

| 项 | 值 |
|---|---|
| 工具 | Video2X（Real-ESRGAN 2x） |
| 输入 / 输出 | 864×480 → 1728×960 |
| 帧数 / 耗时 | 122 帧 / 18.3 秒 |
| 处理速度 | **7.18 FPS** |
| GPU | RTX 3050 Laptop（4GB） |

> 注意：Real-ESRGAN 在指定 `-s`（缩放倍数）时 **`-w/-h` 会被忽略**，输出尺寸由倍数决定。

## 8. 口径说明（面试被追问时用）

- **"$0.1 以内"**指的是**单次生成的云端计算成本**（热容器 + 8 步场景）。
- **"降低成本约 60%"**指的是**采样阶段**：步数由 20 → 8，采样耗时约降为 40%。
  不要把它说成"整体成本降低 60%"——整体成本里模型加载占大头。
- 若被问"怎么算的"：按 Modal 计费单价 × 实测各阶段耗时折算，上表即测算过程。
